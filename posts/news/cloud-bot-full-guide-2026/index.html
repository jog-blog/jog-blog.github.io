ClawdBot 全面攻略：12万星标开源AI助理，本地部署+国内适配全教程

Wednesday, Feb 4, 2026 | 3 minute read | 0 | Updated at Wednesday, Feb 4, 2026

@ 工具测评室

ClawdBot 一夜爆火！这款可运行在本地电脑的开源AI助理，凭借强大的自动化能力和灵活的适配性，短短几天内GitHub星标数量直线飙升，突破12万，成为近期最受关注的AI工具之一。

本期将为大家带来 ClawdBot 完整攻略，从核心优势、本地部署，到基础命令、多场景实测，再到国内网络适配（飞书接入+国产模型配置），10+实用玩法一次性解锁，帮你轻松玩转这款开源AI助理，让它成为你的高效办公好帮手。

先插一个小插曲：受Anthropic法务团队压力，ClawdBot 先后改名为 Mount BT、Open Cloud，改名速度甚至超过了内容更新节奏。为了方便大家理解，本文全程统一称呼其最初的名字——ClawdBot。

一、核心优势：ClawdBot 凭什么脱颖而出？

ClawdBot 功能上与 Cloud Code、Open Code 有相似之处，均可处理文件、编码、调用Skills、MCP等办公任务，但它的3个核心优势，让它在众多AI Agent中脱颖而出：

1. 多聊天工具适配，随时随地远程操控

这是 ClawdBot 最突出的优势——可接入各类聊天工具（WhatsApp、飞书等），即便出门在外、手边没有电脑，只需在聊天工具中给 ClawdBot 留言，它就能自动执行任务，还会将屏幕截图、执行过程等信息实时同步到手机，远程办公、应急处理任务更便捷。与常规AI工具需打开专属网站或App交互不同，ClawdBot 可直接在你常用的通讯软件中对话，无需额外切换应用，碎片化时间也能高效下达指令。

2. 强大的定时任务系统，具备主观能动性

ClawdBot 自带灵活的定时任务系统（Cron jobs），无需复杂指令，用自然语言就能创建定时任务：比如设置临时提醒、定时检查收件箱、定时生成简报等。它还能智能判断事情的紧急程度，自主选择是否通过聊天工具与用户沟通，相比传统固定流程的指令执行，更具“智能感”和主观能动性。值得一提的是，这个看似基础的功能，恰恰弥补了常规AI模型无法执行预定计划任务的短板，让ClawdBot 真正具备了“助理”的主动服务属性，而非单纯的“指令执行者”。

3. 长期记忆功能，越用越聪明

ClawdBot 支持长期记忆存储，可将对话记忆、操作记录以文件形式保存到本地，日常对话中能自动搜索相关记忆并调用到上下文。随着使用次数增加，它会主动更新记忆文件，贴合你的使用习惯、办公偏好，甚至能记住你常用的文件路径、指令风格，真正实现“越用越聪明”，无需每次重复说明基础需求，大幅提升交互效率。

二、本地部署：从零搭建 ClawdBot（详细步骤）

ClawdBot 可在任意支持 Node.js 的环境中部署，最推荐使用 Mac、Linux 系统（或Windows系统搭建Linux虚拟机），其中 Mac mini 是目前最热门的部署方案——桌面环境完善、功耗低（适合7×24小时运行）、与 ClawdBot 众多Skills生态绑定，下面以 Mac 系统为例，详细讲解部署步骤，全程无复杂代码，新手也能轻松上手。

1. 环境准备：安装 Node.js

  1. 访问 Node.js 官网 ，复制首页的安装命令（对应Mac/Linux系统）；
  2. 打开终端，依次粘贴并执行官网提供的3条命令，完成 Node.js 安装；
  3. 安装完成后，输入 node -v 验证是否安装成功（显示版本号即为成功）。

2. 安装 ClawdBot

  1. 访问 ClawdBot 官网，找到安装命令（注意：官网可能已更新为新名称 Open Cloud，若使用官网一键安装命令，后续所有操作需以 Open Cloud 为前缀；本文选用 NPM 安装方式，仍以 ClawdBot 为命令前缀，适配大家习惯的称呼）；
  2. 复制 NPM 安装命令（npm install -g clawd-bot），粘贴到终端执行，等待安装完成（若出现权限报错，可在命令前添加 sudo 提升权限）；
  3. 输入 clawd bot onboard 启动初始化配置，进入下一步设置。

3. 初始化配置（关键步骤）

（1）配置 AI 模型

  • 初始化后，首先选择需要接入的AI模型，支持 OpenAI、国产模型（后续详解国产模型配置）；
  • 本文先以 OpenAI 为例，选择 OpenAI → 勾选 ChatGPT → 登录自己的 ChatGPT 账号（需有 Plus 订阅）；
  • 默认模型选择 GPT-5.2，完成模型配置。

（2）绑定聊天工具（以 WhatsApp 为例）

  • 选择需要绑定的聊天工具（本文先绑定 WhatsApp，后续详解飞书绑定）；
  • 打开手机 WhatsApp → 右上角“三个点” → 关联设备 → 关联新设备；
  • 用手机扫描终端显示的二维码，完成绑定，后续可通过 WhatsApp 远程操控 ClawdBot。

（3）预装 Skills 与 API 配置

  • 按空格键勾选需要预装的 Skills（按需选择，建议勾选浏览器操作、文件处理、定时任务等核心Skills）；
  • 后续出现的 API 配置，可全部选择“跳过”（无需额外配置，不影响基础使用）。

（4）人设配置

  • AI 会询问关于助理人设的问题（如“希望助理的语气是正式还是活泼”），按需回答，完成人设定制；
  • 配置完成后，发送一条测试消息，手机能收到 ClawdBot 的回复，即表示初始化全部成功。

三、基础命令：快速上手 ClawdBot

初始化完成后，掌握以下基础命令，就能轻松操控 ClawdBot，所有命令均在终端执行：

命令功能说明
clawd bot gateway启动 ClawdBot 主程序（关闭终端则停止运行）
clawd bot tui新开终端窗口执行，进入控制台对话界面
clawd bot dashboard进入网页版控制台，可管理对话、定时任务、Skills 等
clawd bot china slogout退出已绑定的聊天工具登录（解决聊天工具掉线问题）
clawd bot login重新登录聊天工具，适配掉线场景

四、多场景实测：ClawdBot 核心功能玩法

结合日常办公需求，实测5个高频场景，带你感受 ClawdBot 的强大，所有操作均可通过远程聊天工具、终端、网页控制台发起。

场景1：定时任务（核心玩法）

测试任务：提醒我2分钟后关煤气

  • 操作：在 WhatsApp/终端输入指令“提醒我2分钟以后关煤气”；
  • 效果：ClawdBot 立即回复“已设定成功”，可在网页版控制台“Crown Job（定时任务）”中查看任务进度；
  • 触发：2分钟后，手机会收到 ClawdBot 的提醒消息，精准执行定时任务。

场景2：浏览器自动化（文件下载）

测试任务：打开 Chrome 浏览器，访问 MIT 公开课官网，下载 Python 课程课件，解压后发送第一节课课件

  • 操作前提：Mac 系统需提前安装 Chrome 浏览器；
  • 操作：输入指令“打开 Chrome，访问 MIT 公开课，下载 Python 课程课件到桌面，解压后发送第一节课课件”；
  • 效果：
    1. ClawdBot 自动打开 Chrome，搜索并进入 MIT 公开课官网；
    2. 搜索 Python 课程，列出课程编号供选择，确认后自动下载课件到桌面；
    3. 调用 Mac 命令行工具解压课件，找到第一节课课件并发送到绑定的聊天工具/本地桌面。

场景3：定时简报（浏览器自动化+定时任务组合）

测试任务：每天早晨8点，查询 GitHub 热点，生成中文简报发送到手机

  • 操作：
    1. 先输入指令“查询 GitHub 热点，生成中文简报发送给我”，测试简报生成效果；
    2. 再输入指令“每天早晨8点，重复执行这个任务，发送简报给我”；
  • 效果：ClawdBot 自动创建定时任务，每天8点准时调用浏览器查询 GitHub 热点，生成简报并推送至手机，无需手动干预。

场景4：屏幕截图（远程监控）

测试任务：远程让 ClawdBot 截取 Mac 桌面屏幕，发送到手机

  • 操作前提：给终端授予录屏/录音权限（Mac 设置 → 隐私与安全 → 录屏与系统录音 → 勾选终端），重启 ClawdBot；
  • 操作：在手机聊天工具输入指令“给当前 Mac 桌面截一张图，发送给我”；
  • 效果：ClawdBot 立即截取桌面屏幕，实时发送到手机，可远程监控电脑状态。

场景5：AI 编程（调用 Coding Agent）

测试任务：调用 Codex，创建一个贪吃蛇游戏

  • 操作前提：安装 Coding Agent Skill，登录自己的 Codex 账号；
  • 操作：在手机聊天工具输入指令“调用 Codex，创建一个贪吃蛇游戏”；
  • 效果：ClawdBot 自动驱动 Codex，完成贪吃蛇游戏的代码编写，生成可运行的程序文件，无需手动敲一行代码。

五、国内适配：飞书接入+国产模型配置（关键！）

前面绑定的 WhatsApp 的国内网络无法正常使用，下面详解“飞书接入+国产模型配置”方案，让 ClawdBot 在国内网络环境下顺畅运行。

第一步：接入飞书（国内聊天工具适配）

（1）飞书开放平台配置

  1. 访问 飞书开放平台 ，登录飞书账号 → 点击“创建企业应用”；
  2. 填写应用名称、描述，完成创建 → 左侧导航栏“添加应用能力” → 选择“机器人”；
  3. 进入“权限管理” → 点击“添加权限”，勾选所有需要的权限（重点勾选“消息发送”“文件传输”“屏幕截图”权限）；
  4. 进入“版本管理与发布” → 填写版本号 → 点击“发布”，完成飞书应用配置。

（2）终端配置飞书插件

在终端依次执行以下4条命令，完成飞书接入（复制命令时注意替换自己的 App ID 和 App Secret）：

  1. npm install -g clawd-bot-feishu（安装飞书插件）；
  2. clawd bot configure feishu appid [你的飞书App ID]（配置 App ID，从飞书开放平台“凭证与基础信息”中获取）；
  3. clawd bot configure feishu appsecret [你的飞书App Secret]（配置 App Secret，同上）；
  4. clawd bot configure feishu enable true（开启飞书适配）；
  5. clawd bot configure feishu linktype WEBSOCKET（设置链接方式为 WEBSOCKET）；
  6. 重启 ClawdBot（执行 clawd bot gateway），完成飞书绑定。

（3）飞书测试

  • 打开飞书 → 找到创建的 ClawdBot 应用 → 发送测试消息（如“你好”“给 Mac 截一张图”）；
  • 若能收到回复并执行对应操作，即表示飞书接入成功，国内网络可正常使用。

第二步：配置国产模型（替代 OpenAI）

本文以 MiniMax 为例（ClawdBot 作者推荐），适配国内网络，无需科学上网：

  1. 访问 MiniMax 开放平台 → 注册登录 → 左侧“接口密钥” → 创建 API Key；
  2. 打开终端，执行 clawd bot configure → 选择“MiniMax”；
  3. 粘贴创建的 MiniMax API Key，一路回车，完成模型配置；
  4. 执行 clawd bot models → 切换默认模型为 MiniMax，重启 ClawdBot 即可生效。

六、高级玩法：接入第三方生态（Skills + MCP）

ClawdBot 的强大之处，在于可通过 Skills、MCP 接入各类第三方生态，拓展更多功能，实测2个高频高级玩法：

玩法1：接入谷歌生态（邮件管理）

（1）配置步骤

  1. 在网页版控制台 → Skills → 搜索“Google Skills” → 点击安装（需将 Mac 系统更新到最新版，避免安装失败）；
  2. 访问 Google Cloud 平台 → 左侧“API 与服务” → “Oauth 权限请求” → 创建客户端应用（选择“桌面 App”）；
  3. 下载生成的 JSON 认证文件，拖拽到 ClawdBot 控制台，完成谷歌生态认证；
  4. 登录谷歌账号，授予邮箱、日历等权限，完成配置。

（2）实测功能

  • 指令“查看我的谷歌邮箱，总结所有未读邮件”：ClawdBot 自动读取邮箱，生成未读邮件总结；
  • 指令“删除所有垃圾邮件，有新邮件时每2分钟提醒我一次”：自动执行删除操作，并创建定时心跳检查，新邮件实时提醒；
  • 指令“发送一封邮件给XXX，主题为‘ClawdBot 测试’，内容为‘实测成功’”：自动撰写并发送邮件，无需手动打开邮箱。

玩法2：接入 MCP（百度地图示例）

（1）配置步骤

  1. 在网页版控制台 → Skills → 搜索“MCP Porter” → 点击安装；
  2. 访问 百度地图开放平台 → 注册登录 → 创建应用 → 获取 API Key；
  3. 输入指令“用 MCP Porter 配置百度地图 MCP，API Key 为XXX”（粘贴自己的百度地图 API Key）；
  4. AI 会提供3种安装方案，选择“STREAMABLEHTTP”，完成配置。

（2）实测功能

  • 指令“查询从青岛太平角公园到崂山仰口景区的路线，步行+驾车方案都要”：ClawdBot 调用百度地图 MCP，生成详细路线规划，发送到手机/控制台，适配出行需求。

七、注意事项与常见问题

  1. 名称适配：ClawdBot 已改名为 Open Cloud，若使用官网一键安装，所有命令需替换为“open cloud”前缀，本文 NPM 安装方式仍可用“clawd bot”前缀；
  2. 权限问题：Mac 系统中，终端需授予录屏、录音、文件读写权限，否则无法执行截图、文件处理等操作；
  3. 掉线问题：聊天工具（飞书、WhatsApp）若出现掉线，执行 clawd bot china slogout 退出登录，再执行 clawd bot login 重新绑定即可；
  4. 系统适配：Windows 系统需搭建 Linux 虚拟机，部署步骤与 Mac/Linux 一致，仅环境准备略有差异；
  5. 模型适配：国产模型无需科学上网，适合国内用户，但部分高级 Skills 可能更适配 OpenAI 模型，可按需切换。

结语：开源AI助理的终极形态，办公效率翻倍

从本地部署到远程操控，从基础文件处理到高级生态联动，ClawdBot 用12万星标证明了自己的实力——它不仅是一款AI助理，更是一款可自定义、可拓展的本地自动化工具。

对于国内用户而言，飞书+国产模型的适配方案，彻底解决了网络限制问题，出门在外也能远程操控本地电脑，处理文件、查询信息、定时提醒、编程开发，一站式完成所有重复性办公任务。

随着开源社区的迭代，ClawdBot 的 Skills 会越来越丰富，适配的生态也会越来越广。如果你经常被重复性办公任务困扰，想要一款可自定义、高灵活度的AI助理，ClawdBot 绝对值得一试。
