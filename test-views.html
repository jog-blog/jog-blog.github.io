浏览量统计测试

测试步骤：

  1. 打开浏览器开发者工具(F12) -> Console标签页
  2. 复制粘贴下面的清理脚本并执行
  3. 刷新博客首页
  4. 点击进入某篇文章
  5. 观察控制台输出和浏览量变化

清理脚本：

// 清理localStorage中的浏览量数据
Object.keys(localStorage).forEach(key => {
  if (key.startsWith('views_')) {
    console.log('删除:', key, '=', localStorage.getItem(key));
    localStorage.removeItem(key);
  }
});

// 清理会话标记
Object.keys(sessionStorage).forEach(key => {
  if (key.startsWith('session_viewed_')) {
    sessionStorage.removeItem(key);
  }
});

console.log('清理完成！');

预期结果：

  • 首次访问文章：浏览量从0增加到1
  • 同一会话再次访问：浏览量保持不变（防止重复计数）
  • 新会话访问：浏览量继续增加
  • 首页和详情页显示相同的浏览量
